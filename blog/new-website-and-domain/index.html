New website and domain

Hello, Crystal community!

I’m excited to share that Ameba finally has a proper home on the web — a dedicated website and domain.

Up until now, our online presence has mostly been centered around the GitHub repository. While that’s still where all the development happens, we felt it was time to give Ameba a more accessible and user-friendly face.

Welcome to crystal-ameba.org — the new official website for Ameba.

First of all, a big thank you to @veelenga for creating the new website! ❤️

The site is built with Astro and is designed to be a central hub for documentation, guides, and announcements. Here’s what you can expect:

  • Easier onboarding — A streamlined getting-started guide for new users.
  • Blog — A place for project news, releases, and community updates (you’re reading it!).
  • Clearer documentation — In the future, organized rule references and configuration guides will be available as well.
  • Open source — The website itself is open on GitHub, so contributions are welcome.

This move also comes with a new domain — crystal-ameba.org — which we hope will be easier to remember and share.

API documentation URLs are now versioned (crystal-ameba.org/api/<version>) and have changed the address from crystal-ameba.github.io/ameba to crystal-ameba.org/api/master.

If you have any feedback or ideas for the website, feel free to open an issue or reach out on the Crystal community channels.

Cheers,
@Sija
